6. API: estatísticas das atividades
-----------------------------------------------------

- O Painel Inicial precisa de totais: distância, tempo e quantidade de
  treinos, no geral e por tipo de atividade. Em vez de trazer todas as
  atividades e somar no navegador, pedimos ao banco de dados que some
  (consulta agregada, com SUM, COUNT e GROUP BY).

- O código desta seção está pronto para copiar. Leia os comentários para
  entender o que cada parte faz.

Na API:

- Crie o record ActivityTypeStatistic, no pacote repository.projection:

package br.edu.ifspcjo.ads.web2.ifitness.repository.projection;

import br.edu.ifspcjo.ads.web2.ifitness.domain.model.ActivityType;

// Totais de um tipo de atividade (uma linha do resultado da consulta agrupada)
public record ActivityTypeStatistic(
		ActivityType type,
		Long total,
		Double distance,
		Long duration) {
}

- Crie o record ActivityStatistics, no mesmo pacote:

package br.edu.ifspcjo.ads.web2.ifitness.repository.projection;

import java.util.List;

// Resumo das atividades de um usuário, exibido no painel inicial
public record ActivityStatistics(
		Double totalDistance,
		Long totalDuration,
		Long totalActivities,
		List<ActivityTypeStatistic> byType) {
}

- Na interface ActivityRepository, adicione os imports:

import org.springframework.data.jpa.repository.Query;
import org.springframework.data.repository.query.Param;

import br.edu.ifspcjo.ads.web2.ifitness.repository.projection.ActivityTypeStatistic;

- Na mesma interface, adicione o método:

	@Query("select new br.edu.ifspcjo.ads.web2.ifitness.repository.projection.ActivityTypeStatistic("
			+ "a.type, count(a), sum(a.distance), sum(a.duration)) "
			+ "from Activity a "
			+ "where a.user.email = :email "
			+ "group by a.type")
	public List<ActivityTypeStatistic> statisticsByType(@Param("email") String email);

- Na classe ActivityService, adicione os imports:

import br.edu.ifspcjo.ads.web2.ifitness.repository.projection.ActivityStatistics;
import br.edu.ifspcjo.ads.web2.ifitness.repository.projection.ActivityTypeStatistic;

- Na mesma classe, adicione o método:

	public ActivityStatistics statistics(String email) {
		List<ActivityTypeStatistic> byType = activityRepository.statisticsByType(email);

		double totalDistance = 0;
		long totalDuration = 0;
		long totalActivities = 0;
		for (ActivityTypeStatistic statistic : byType) {
			totalDistance += statistic.distance();
			totalDuration += statistic.duration();
			totalActivities += statistic.total();
		}

		return new ActivityStatistics(totalDistance, totalDuration, totalActivities, byType);
	}

- Na classe ActivityResource, adicione os imports:

import org.springframework.security.core.Authentication;

import br.edu.ifspcjo.ads.web2.ifitness.repository.projection.ActivityStatistics;

- Na mesma classe, adicione o método (antes do método findById):

	@GetMapping("/statistics")
	@PreAuthorize("hasAuthority('ROLE_SEARCH_ACTIVITY')")
	public ActivityStatistics statistics(Authentication authentication) {
		// authentication.getName() devolve o e-mail do usuário dono do access token
		return activityService.statistics(authentication.getName());
	}

  Observação: o usuário não é enviado como parâmetro. A API descobre quem é
  o usuário pelo access token, então ninguém consegue ver as estatísticas de
  outra pessoa.

import { ErrorHandlerService } from '../core/error-handler.service';
import { ActivityStatistics } from '../core/model';

@Component({
  selector: 'app-dashboard',
  standalone: true,
  imports: [
    CommonModule
  ],
  providers: [
    Title
  ],
  templateUrl: './dashboard.component.html',
  styleUrl: './dashboard.component.css'
})
export class DashboardComponent implements OnInit {

  statistics: ActivityStatistics = {
    totalDistance: 0,
    totalDuration: 0,
    totalActivities: 0,
    byType: []
  };

  typeLabels: any = {
    CAMINHADA: 'Caminhada',
    CICLISMO: 'Ciclismo',
    CORRIDA: 'Corrida',
    NATACAO: 'Natação'
  };

    private activityService: ActivityService,
    private errorHandler: ErrorHandlerService,
    private title: Title
  ) { }

    this.title.setTitle('Painel Inicial');
    this.loadStatistics();

  loadStatistics(): void {
    this.activityService.statistics()
      .then(statistics => {
        this.statistics = statistics;
      })
      .catch(error => this.errorHandler.handle(error));
  }

}

- No mesmo arquivo, adicione o método buildChart() e chame-o depois de
  receber as estatísticas:

  loadStatistics(): void {
    this.activityService.statistics()
      .then(statistics => {
        this.statistics = statistics;
        this.buildChart();
      })
      .catch(error => this.errorHandler.handle(error));
  }

  buildChart(): void {
    this.chartData = {
      labels: this.statistics.byType.map(item => this.typeLabels[item.type]),
      datasets: [
        {
          data: this.statistics.byType.map(item => item.total),
          backgroundColor: ['#198754', '#0d6efd', '#ffc107', '#dc3545']
        }
      ]
    };
  }

  Observação: map() transforma uma lista em outra. Aqui, a lista de
  estatísticas vira a lista de nomes (labels) e a lista de quantidades (data).
